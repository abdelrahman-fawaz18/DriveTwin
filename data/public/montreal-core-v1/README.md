`roads.osm.xml` is reviewed public road/topology data, with contributor/account metadata and unrelated node details removed. `source.json` records the exact source query, actual download endpoint/date, database timestamp, content fingerprints, filtering and limitations. The original download stays ignored under `data/downloads/`.

Keep this notice and source record when redistributing the data. Future maps/simulation displays must visibly attribute OSM and link its license information. Derived geographic exports need corresponding ODbL review and attribution; do not relabel them under a future code license.

This is a fixed research/development snapshot, with no live traffic, actual bus readings, certified route suitability or real charging availability. Use the existing snapshot for offline reproduction. Fetching current data creates a new input requiring a new version and qualification, not an identical reconstruction of this dated snapshot.
