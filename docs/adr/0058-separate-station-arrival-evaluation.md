# ADR 0058. Measure station arrivals before scoring charging forecasts

Use a dedicated offline reference collector with SUMO as the sole battery and motion owner. Reuse the same reviewed network import, physical assumptions, and step energy reconciliation as monitoring. A separate scheduled station stop and declared wait keep this experiment independent of the existing product route and command sources. Record actual lane position and stationary state, arrival and minimum battery energy, and equipment draw during a no-charge wait. Keep the per-step simulator trace in private evidence. [Reference drive guide](../setup/station-arrival-reference-drives.md)

Predeclare separate development and reserved approaches for each station. The development collector may check every planned route without stepping the reserved drives. Freeze an observable input contract, candidate and baseline versions, numeric error and interval limits, and reserve classification rules before collecting or scoring reserved outcomes. Preserve the Phase 2 known-route evidence as its own experiment. These station references support later prediction development. Station-arrival accuracy, live input qualification, and dispatch approval remain open.
