# ADR 0047. Authenticate and persist the first connected command

Use an optional command service alongside the local monitoring stack. The command service exposes a loopback HTTP endpoint for the operator and a credential-protected handoff for the simulator. A bearer token is a secret presented with a request. The operator and simulator use distinct tokens. Monitoring and replay readers keep their own credentials. The simulator receives only its executor token and connects over the internal Docker network.

Reuse the monitoring PostgreSQL instance and give the command service its own schema and database login. An administrator assigns one operator and one bus from a registered simulation run. The command service uses one database connection at a time. Its login can read the target assignment and append request, reservation, and result records. It cannot rewrite those records or read the raw monitoring tables.

The operator submits an encoded command and can retrieve its status by command ID. The coordinator checks the configured target, issuer, command rules, and wall deadline before saving the request. A command can wait for its simulation window to open. At the simulation step boundary, the executor supplies the current simulation time. The service verifies both clocks and commits a reservation before returning the request. The executor rechecks the command and local speed ceiling before applying it. This increment permits one request and one reservation for the assigned bus and run.

Exact command retries return the stored state. A second command for the same run and bus or changed bytes under the same command ID produce a conflict. The result refers to the reserved command and simulation instant. Identical result retries return the saved result. A reservation with no recorded result is displayed as `unknown_outcome`. That reservation remains in the database and prevents another handoff, including when the first response was lost. The full crash and reconciliation matrix is later Phase 3 work.

Keep the simulator acknowledgment separate from observed speed. Use the same short route comparison as the first Phase 3 checkpoint. The optional Compose service connects the local command exercise to PostgreSQL and authenticated operator access.
