# ADR 0069. Isolate combined charging and cooling

Use a fresh, isolated simulation run and one registered bus for each P6-C1 case. The test adapter owns changes to both the SUMO route and the synthetic cooling plant. The existing charging service keeps its operator and executor roles. Its durable claim hands a route to the adapter, which checks the run, bus, deadline, and actual charger power before use. The separate Phase 4 automatic profile is disabled.

Reuse the normal disk-backed telemetry queue, message broker, database ingestion, and read service. Register the speed and motor temperature signals with the existing supported catalog. For the cooling case, retain the housing probe inside the isolated fixture and match it to the same thermal tick. The combined recipe binds the existing simulated departure network and its own thermal inputs. A two-node thermal model represents the motor and housing as separate heat stores. The test evolves the model and a matched no-boost copy from the same condition. It uses the frozen Phase 5 advisory and boost admission rules. This fixture tests wiring and authority under synthetic conditions. The Phase 5 accuracy and effect evidence keeps its own scope.

The outage cases stop the broker while the source can still save new telemetry to its queue. They withdraw physical charger power while the broker is down. After the broker and ingestion restart, the test checks original telemetry and the durable command state independently. A reserved command with no verified effect remains unresolved. For the queued case, current observations supersede the evidence that authorized the old request. The existing service allows one charging request per run, so the recovery cases record the blocked outcome on that identity. The healthy case separately verifies an eligible request on a fresh run.

The host check and source checks precede execution. Start cases sequentially with owned Docker resources. Use new evidence directories and retain failed cases. Review charging and cooling effects from measurements and reconcile the charging effect through the observer role.
