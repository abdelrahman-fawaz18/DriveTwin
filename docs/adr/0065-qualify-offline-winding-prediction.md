# ADR 0065. Qualify offline winding prediction

Use a passive heat balance to predict the testbench winding temperature. Test a single temperature state and a network with a second effective motor-body state. Both candidates use the same admitted input columns and initial winding temperature. Select the two-state model only if it improves the validation mean absolute error by more than 0.15 K. This margin favors a smaller model when validation errors are close. [A2 input decision](0064-separate-motor-testbench-and-bus-thermal-evidence.md) · [Development policy](../../qualification/thermal/bench-development-1.0.0.json)

Fit effective rates and gains using the training recordings. The bench data identifies ratios such as thermal conductance divided by heat capacity. An assumed capacity scale converts these to a consistent heat balance for simulation. The effective parameters alone cannot establish physical motor constants. Score each profile separately and weight profiles equally in the aggregate. Use the one measured startup value for the primary trajectory and evaluate ambient-only startup separately.

Check state observability in a separate synthetic two-temperature experiment. Observability means the temperature history contains enough information to infer a state that has no direct sensor. Compare predictions made before each noisy winding sample arrives. A Kalman filter adjusts the estimated temperatures after each sample, using uncertainty in the model and sensor to set the correction. The synthetic comparison requires a winding sensor and heat exchange between states. The actual bench release keeps open-loop predictions after startup, and the effective body state remains a synthetic study result. [Qualification guide](../setup/bench-thermal-qualification.md)

Derive error limits and the empirical prediction band from the validation results within the recorded caps. Commit the model, source fingerprints, scoring code, and limits before opening the reserved outcomes. A local claim prevents a second evaluation of the same reserved split through this entry point. The release applies to the identified testbench and input protocol. The simulated bus and future fault experiments require separate evidence and parameter assumptions.
