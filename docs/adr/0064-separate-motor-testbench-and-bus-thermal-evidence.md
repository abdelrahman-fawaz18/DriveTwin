# ADR 0064. Separate motor testbench and simulated bus evidence

Use the audited Paderborn recording as the source for a testbench prediction study. Freeze its whole-session assignment and the allowed model inputs before fitting. Screen possible repeated sessions using only speed, torque, and session length. Keep linked sessions together and balance the partitions by recorded duration. The input-only screen covers near-repeats of comparable length and aligned timing. Evaluation claims apply to reserved sessions of the same testbench, with session family metadata unavailable. [Frozen split](../../qualification/thermal/motor-profile-split-1.0.0.json) · [Authors' validation scheme](https://arxiv.org/html/2103.16323#S3.SS1.SSS2)

Use stator winding temperature as the initial bench study target. The winding is the wire coil in the stationary part of the motor. Include ambient and coolant temperatures, shaft speed, and the sum of the squares of the two motor current components. Use the sum as an input related to heating. A calibrated loss term and its units belong to the model work. Initialize the primary prediction with one measured winding temperature at the start of each session and score only later samples. Include a separate ambient-initialized run to measure performance when a winding reading is unavailable at startup. [Input contract](../../qualification/thermal/motor-input-contract-1.0.0.json)

Keep the simulated bus study on its own inputs, parameter assumptions, and reference scenarios. The bus provides calculated shaft speed and torque, an aggregate modeled motor temperature, and an assumed ambient temperature. Its second asset adds a modeled coolant inlet. These measurements support an aggregate simulated thermal study. Motor-axis electrical measurements, component-level thermal labels, and coolant flow need additional evidence before a model can rely on them. Phase 5 fault and intervention tests use independently generated bus scenarios with known fault timing. [Signal map and verification](../setup/motor-profile-split.md)
