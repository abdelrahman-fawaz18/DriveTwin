# ADR 0066. Synthetic thermal advisory and timing

Use a separate bus thermal fixture for fault detection. The reference simulation records actual cooling effectiveness, sensor injections, and true-temperature threshold crossings for scoring. The monitor consumes timestamped temperature readings and predictions from a healthy reference initialized with startup readings. The scorer receives the fault labels separately. The synthetic experiment uses independent parameters and seeds, with the physical testbench study retained as winding-prediction evidence. [Fault protocol](../../qualification/thermal/synthetic-fault-protocol-1.0.0.json)

Require elapsed persistence before issuing an advisory. A positive motor residual means the measured motor is hotter than expected. An independent, synchronized housing measurement can corroborate that deviation in the two-probe fixture. A single probe or conflicting evidence yields an ambiguous advisory. A temperature jump latches sensor suspicion for the session. Missing, repeated, stale, and invalid primary inputs reset persistence. Losing housing evidence resets corroboration. The temperature must stay at or below a lower clearing threshold for the specified interval to clear an active deviation.

Use a small explicit state machine for decisions and RTAMT for an independent check of the bounded persistence rule. RTAMT evaluates Signal Temporal Logic, which expresses rules over a timeline. Its periodic truth trace assumes eligible readings have already been identified. The state machine handles input age, repeated timestamps, missing evidence, latching, and transitions. Keep the RTAMT package in an isolated verification environment. [RTAMT project](https://github.com/nickovic/rtamt) · [Advisory guide](../setup/synthetic-thermal-fault-qualification.md)

Freeze the candidate, limits, source fingerprints, and separate development and reserved scenario seeds before the reserved evaluation. Report detection and timing within the defined fixture, including cases where diagnosis must remain ambiguous. The housing probe is an additional synthetic measurement for this qualification. The existing bus aggregate motor temperature supports the single-probe comparison. This checkpoint produces advisory evidence. Intervention safety and effectiveness belong to the subsequent command and simulator studies.
