# ADR 0063. Qualify one automatic diversion from a parked simulator

The approved automatic trial uses the isolated configuration proposed in [ADR 0062](0062-registered-charging-and-matched-outages.md). The [versioned profile](../../qualification/charging/automatic-departure-1.0.0.json) applies to one registered synthetic bus in a fresh local simulation run. It permits one diversion, from rest, using the reviewed station catalog and frozen model. It has a one-second simulation window and a three-second elapsed-time deadline. The regular monitoring and operator charging setups do not enable it.

Bind the profile fingerprint to the trusted run recipe and registered source. Only the separate policy credential can ask the service to propose automatically. The service chooses from authenticated observations and saves the policy identity, decision fingerprint, and proposed action. The caller cannot nominate a charger. The operator can latch an override for the rest of the run. Operator submission of a competing diversion is refused in this profile.

An executor first reserves the proposal. The reservation contains no actuation instructions. A second request checks current inputs, authority, protective limits, station eligibility, and both deadlines. The service gives the route only after saving a one-use grant. These database changes and the operator override share a lock, so the order is explicit. An override committed before the grant prevents release. The grant is the last software handoff; an override after it cannot undo a route change already in progress. The adapter independently verifies the real deadline, simulation time, stationary bus, and physical charger power before changing the route.

A service restart changes its process identity. It cannot release a grant from a reservation made by the prior process. A grant already saved cannot be sent again. The result remains unknown until an independent observer reconciles the measured charge, target, resumed motion, and mission arrival. This does not claim physical exactly-once execution or controller redundancy. The qualification uses one service process, isolated credentials, and no physical vehicle connection.

At closeout, compare the three policies again with only the common station power state at departure. The separate parked-history run demonstrates recommendation stability before departure; it is not the controlled comparison. The controlled scenarios do not exercise real occupancy, delayed external status feeds, moving custom replanning, or identical policy charge targets. Those conditions require their own qualified design before extending the operational claim.
