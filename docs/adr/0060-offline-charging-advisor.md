# ADR 0060. Evaluate station eligibility before ranking

Use a separate offline scenario contract with one vehicle, one mission, simulation decision times, and station observations with availability times. Verify the station forecast release and archived network before replay. Check current stationary departure, connector compatibility, reachable lane stop and mission rejoin, station freshness and occupancy, expected wait, and conservative reserve. Record each exclusion alongside the facts the evaluator could see. Leave unknown departure state or an empty eligible set visible in the decision record.

Rank eligible stations by estimated seconds added to the mission. Compare the original and via-station paths to the same required stop or mission finish. Record travel, wait and charge separately. Compare with the nearest feasible station using the same candidate set. Treat the post-charge budget and acceptance limits as declared offline inputs. The charge calculation uses constant net power until Phase 4C measures the selected charging behavior.

Use a 30-second gain, 20-second persistence, 60-second cooldown, and maximum 10-second decision gap for voluntary switches. Reset the pending improvement when the gain fades, the challenger changes, or a sample is missing beyond the gap. Replace an ineligible incumbent as soon as a valid update makes that loss visible. Clear the recommendation when no candidate remains. The offline record carries scenario, policy, runner, network, and release fingerprints.
