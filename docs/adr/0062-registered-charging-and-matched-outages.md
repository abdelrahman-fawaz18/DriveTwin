# ADR 0062. Register operator charging and compare physical outages

Use a separate charging overlay on the existing authenticated command service. Bind the simulated bus to the frozen forecast, station catalog, and network before accepting departure measurements. Require separate authenticated station observations and a scoped operator request for the resulting decision. A database reservation must commit before the executor receives the diversion. Treat an interrupted handoff as unknown and never issue it again. Only corroborating observations can record an effect. Keep the existing monitoring and Phase 3 configurations unchanged.

Allow one operator diversion per run and bus in this profile. Reject noncharging command writes in the overlay so another command controller cannot compete in the qualified configuration. Other profiles keep their existing routes. The charging fixture drives the same service interfaces with distinct role credentials; this is a test harness, not a deployment model for storing credentials together. The charging inputs and effects use dedicated authenticated endpoints. They are not the regular dashboard telemetry stream.

Compare the advisor, nearest-feasible station, and native Stationfinder with the same simulator, departure, road network, station geometry, physical outage timeline, and measured reserve termination. Leave Stationfinder in control of its own charging search and turn its rescue action off. Preserve its configured saturation and measured outcome separately. Do not infer comparative performance at an equal finish energy or in a shared queue/status-feed model. Scope custom replanning to the stationary departure supported by the frozen forecast.

Automatic dispatch was disabled at this checkpoint. A separately approved qualification may target only a fresh isolated run, one synthetic bus at rest, one expiring diversion from the verified station catalog, and no real asset or competing actuator. Qualification must demonstrate recorded authority, operator override, thermal and local blocks, stale input, clock expiry, durable restart behavior, and independently observed results.
